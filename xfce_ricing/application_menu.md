NOTES
-----
This new menu requires 4.1 and cannot run on 4.0. This is experimental software for testing purposes only!

INSTALLATION
------------
```text
[user@dom0 ~]$ sudo qubes-dom0-update --enablerepo=qubes-dom0-unstable qubes-desktop-linux-menu
[user@dom0 ~]$ qubes-app-menu &
```
